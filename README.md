# GH-900 GitHub Foundations 受講者向け配布資料

研修で使う演習（GitHub Skills / Microsoft Learn）は英語です。このリポジトリに日本語の手順を置いています。
演習中は、英語の画面とこの日本語を並べて読んでください。

## 使い方

- 演習は GitHub Skills の日本語版テンプレート（`mamezou/skills-ja-*`）から始めます。手順は自分のリポジトリの Issues（M15 は README）に日本語で表示されます。各資料の「演習の開始」リンクから作ってください。
- 各演習は「開始リンク」から自分のリポジトリを作って始めます。リンクは各ファイルの冒頭にあります。
- ボタン名、ファイル名、ブランチ名、コミットメッセージは、画面と同じにするため英語のままです。**指定された名前は変えずに入力してください。** 自動チェックがその名前を見ています。
- 作ったリポジトリと Codespace は、研修が終わるまで削除しないでください（後のモジュールで使います）。Codespace は停止だけしてください。
- 各モジュールの最後に、Microsoft Learn の「モジュール評価」（知識チェック、日本語）を受けます。Learn へのサインインが必要です。
